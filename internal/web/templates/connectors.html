Setup guide: creating a read-only PostgreSQL user

OpenTrace enforces read-only mode automatically, but we recommend connecting with a dedicated user that has minimal privileges. 

-- 1. Create a read-only user
CREATE USER opentrace WITH PASSWORD 'your-secure-password';

-- 2. Grant connect access
GRANT CONNECT ON DATABASE your_database TO opentrace;

-- 3. Grant schema usage and read access
GRANT USAGE ON SCHEMA public TO opentrace;
GRANT SELECT ON ALL TABLES IN SCHEMA public TO opentrace;
ALTER DEFAULT PRIVILEGES IN SCHEMA public
  GRANT SELECT ON TABLES TO opentrace;

-- 4. Grant access to monitoring views
--    (required for activity, locks, and connection tools)
GRANT pg_monitor TO opentrace;

-- 5. Optional: enable pg_stat_statements for query stats
-- CREATE EXTENSION IF NOT EXISTS pg_stat_statements;
  • SELECT ON ALL TABLES — needed by search & schema tools
  • pg_monitor — needed by activity, locks & connection pool tools
  • pg_stat_statements — optional, used by query stats tool
