#Quick Start

  1. Build the binary 
    go install github.com/adham90/opentrace/cmd/opentrace@latest
  2. Configure your agent — add the MCP server config to your client (see sections below)
  3. Verify the connection — ask your agent to list_connectors; it should return your configured data sources

#Claude Code

Add to your project's .mcp.json or global ~/.claude.json under mcpServers:

{
  "mcpServers": {
    "opentrace": {
      "command": "opentrace",
      "args": ["mcp"]
    }
  }
}

#Browser Error Tracking

Capture JavaScript errors from your frontend and forward them to OpenTrace. Errors are grouped automatically and correlated with server-side logs via request ID.

1. Add the script tag

Paste this into your HTML <head>:

loading...

2. Add the request ID meta tag (optional)

To correlate browser errors with the server request that rendered the page, add this meta tag to your layout. For Rails:

<meta name="opentrace-rid" content="<%= request.request_id %>">

For other frameworks, set the content to your server's request ID.

Advanced options

OpenTrace.init() accepts these options:

Option Description Default
service Service name for your frontend (required) --
environment Environment tag (production, staging, etc.) ""
commitHash Git commit hash for release tracking ""
sampleRate Fraction of errors to capture (0.0–1.0) 1.0
beforeSend Function to modify or drop events before sending. Return null to drop. null
maxQueueSize Max buffered events before forced flush 50
flushInterval Flush interval in milliseconds 5000
enabled Kill switch to disable tracking true

Manual error capture

// Capture a caught error with extra context
OpenTrace.captureError(error, { userId: 42, page: '/checkout' });

// Send a manual log message
OpenTrace.log('warn', 'Payment retry attempted', { orderId: 123 });

// Set context merged into every event
OpenTrace.setContext({ userId: 42, plan: 'pro' });

#Environment Variables

Optional environment variables to configure OpenTrace:

Variable Description Default
OPENTRACE_DATA_DIR Directory for SQLite database ~/.opentrace
OPENTRACE_LLM_PROVIDER LLM provider for watchers (openai, anthropic, gemini) openai
OPENTRACE_LLM_MODEL Model name for the chosen provider gpt-4o-mini
OPENAI_API_KEY API key for OpenAI provider --
ANTHROPIC_API_KEY API key for Anthropic provider --
GEMINI_API_KEY API key for Google Gemini provider --
OPENTRACE_PORT HTTP server port 7777
OPENTRACE_API_KEY API key for log ingestion endpoint --

You can pass environment variables to the MCP server by adding an "env" block to the config:

{
  "mcpServers": {
    "opentrace": {
      "command": "opentrace",
      "args": ["mcp"],
      "env": {
        "OPENTRACE_DATA_DIR": "/path/to/data"
      }
    }
  }
}
